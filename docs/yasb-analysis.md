## Widget inventory

`core/widgets/yasb/` includes clock, CPU, memory, GPU, traffic, volume, active window, battery, media, systray, applications, weather/Open Meteo, taskbar, notifications, power menu, custom widgets and launchers. README also lists integrations for GlazeWM, Libre Hardware Monitor and service-specific widgets. Presence is verified; full behavior of every widget has not been audited. Scope is deliberately the core bar first.

## Reusable patterns

Shared native collectors, a widget registry, typed validated configuration, monitor-aware ownership and explicit shutdown are useful patterns. Avoid inheriting process restart reloads or reporting failed hardware reads as valid zeroes. Real Windows behavior and performance remain unverified.
